# Security Policy

## Supported Versions

This project follows the `main` branch for active development and security updates.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

## Reporting a Vulnerability

Please report vulnerabilities privately by contacting:

- Email: `support@legal.testkun.net`

When reporting, include:

1. A clear description of the issue and impact
2. Reproduction steps or proof of concept
3. Affected paths/files and environment details

We aim to acknowledge reports within 3 business days and provide status updates until resolution.

Please do not disclose vulnerabilities publicly until a fix is available.
